1. kind のセットアップ・インストール
2. aqua のセットアップ・インストール
3. `aqua init` コマンドで aqua.yaml ファイルを作成
4. kind でk8sをインストールする
5. cluster.yamlを作成
6. `kind create cluster --config cluster.yaml` を実行 
 - `ERROR: failed to create cluster: node(s) already exist for a cluster with the name "kind"` の場合は一度削除`kind delete cluster`or Dockerで起動
7. `aqua g -i` でkubernetes/kubernetes/kubectl と derailed/k9sを選択
8. `aqua i -l` で追加したツールを使用できるようにする
9. `kubectl get nodes` を実行
10. `  - name: helm/helm@v3.14.4` を aqua.yamlに記載し`aqua install`を実行
11. `aqua g -i` でhelm/helmを選択
12. `helm repo add bitnami https://charts.bitnami.com/bitnami`を実行
13. `helm repo update` を実行
14. `helm install kdg-server-nginx bitnami/nginx` を実行
15. `kubectl port-forward service/kdg-server-nginx 8080:80` を実行
16. [サイト](http://localhost:8080)にアクセス
